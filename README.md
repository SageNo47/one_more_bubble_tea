<h1 align="center">喝了么 · MilkTeaPet</h1>

<p align="center">一只住在 Mac 桌面上的奶茶小伙伴，按时问你“喝了么”，也替你记住喝过的每一杯。</p>

## 怎么用

- 启动应用后，奶茶会出现在桌面右上角；拖动它可以调整位置。
- 鼠标移到奶茶上，它会轻轻摇一摇。
- 单击奶茶，打开“喝了么”日历，查看、添加或删除每日记录。
- 右键奶茶，可以打开记录、进入设置或退出应用。
- 在设置中填写每天的提醒时间和提醒词。提醒出现后，选择“来一杯”即可记下一杯，选择“今天不喝”则关闭提醒。

## 下载与安装

支持 macOS 13 及以上，同时兼容 Apple Silicon 和 Intel Mac。

**[下载 MilkTeaPet 1.0.0（macOS 通用版）](https://github.com/SageNo47/one_more_bubble_tea/raw/main/dist/MilkTeaPet-1.0.0-macOS-universal.zip)**

1. 点击上面的链接下载 ZIP。
2. 解压 ZIP，将 `MilkTeaPet.app` 拖入“应用程序”文件夹。
3. 首次启动时，右键 `MilkTeaPet.app`，选择“打开”，再在提示框中确认。
4. 如果仍被 macOS 阻止，请前往“系统设置 → 隐私与安全性”，找到相关提示并选择“仍要打开”。

之后就可以像普通应用一样启动它了。

## 小提示

- MilkTeaPet 不常驻 Dock；需要退出时，请右键桌面上的奶茶并选择“关闭”。
- 提醒只会在应用保持运行时出现，退出应用后不会在后台提醒。
- 提醒设置和饮用记录都保存在你的 Mac 本地。
