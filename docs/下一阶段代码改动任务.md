# MilkTeaPet 阶段代码改动任务与进度

> 本文记录截至当前版本的产品决策、已完成代码改动和下一阶段建议任务。

## 1. 已确认的产品决策

### D1. 桌面宠物尺寸

- 保持 `112 × 140 pt`。
- 从像素绘制切换为透明插画资源，但窗口尺寸不变。

### D2. 桌面宠物动效

- 默认静止。
- 鼠标进入奶茶图案区域时触发一次整体左右摇动。
- 不实现持续摆动、眨眼或吸管单独摆动。

### D3. 提醒气泡位置

- 优先显示在桌面宠物上方。
- 上方空间不足时允许显示在下方，优先保证窗口完整可见。
- 气泡显示期间持续跟随宠物移动，设置窗口不跟随。

### D4. 提醒规则

- 设置精度为时、分、秒，保存格式为 `HH:mm:ss`。
- 目标时间已经到达、经过或恰好相等时，安排到下一天。
- 保存设置后立即重新安排，不限制同一自然日修改后再次触发。
- 休眠期间错过的提醒不补弹，唤醒后重新计算。

### D5. 设置窗口标题

- 删除设置窗口内的奶茶图案。
- 标题统一为“设置”并真正水平居中。
- 使用紧凑标题区，减少标题与提醒时间区域的纵向间距。

## 3. 已完成代码改动

### 3.1 设置窗口行为

- 使用独立 `SettingsWindowController` 管理显示与关闭。
- 新窗口居中到宠物所在屏幕的可见区域。
- 设置窗口可拖动；再次打开只置前，不切换关闭。
- 宠物移动不会改变设置窗口位置。
- 窗口尺寸最终调整为 `400 × 300 pt`。

### 3.2 提醒调度

- 取消固定周期轮询，改为直接预约下一次目标日期的单次 `Timer`。
- 支持 `HH:mm:ss`，并兼容旧的 `HH:mm` 数据。
- 保存后取消旧计时器并立即重新安排。
- 应用启动时自动安排下一次提醒。
- 监听系统时间、时区、休眠和唤醒事件。
- 防止休眠恢复后补弹延迟超过 60 秒的旧提醒。
- 已删除 `testReminder`、设置页“测试气泡”入口及相关调用链。

### 3.3 提醒气泡定位

- 显示前读取宠物窗口实时位置。
- 监听 `NSWindow.didMoveNotification`，让已显示的气泡持续跟随宠物。
- 根据屏幕可见区域自动选择上方或下方，并限制水平位置。
- 设置窗口与气泡定位逻辑完全解耦。

### 3.4 奶茶外观与动效

- 删除 `PixelMilkTea.swift` 中的像素网格形象。
- 删除“叶师傅”贴纸和 `StickerBadge` 组件。
- 新增透明 PNG 奶茶插画资源，并在 `Package.swift` 中启用资源处理。
- 新增 `MilkTeaArtwork`，使用 `Bundle.module` 加载图片并缓存 `NSImage`。
- 新增 `AnimatedMilkTea` 和 `HoverShakeEffect`。
- 奶茶默认静止，仅在鼠标进入时完成一次约 `0.55s` 的整体摇动。

### 3.5 奶茶数据模型

- 新增 `MilkTea`，包含 ID、名称、主图、可选贴纸、价格最小货币单位、币种、描述和显示配置。
- 新增 `MilkTeaDisplayConfiguration`，保存缩放与偏移参数。
- 新增 `MilkTeaStore`，集中管理奶茶列表和当前选择。
- 新增 `selectedMilkTeaID` 本地存储，为后续桌面形象切换保留接口。
- 当前 UI 仅消费桌面宠物图案，不展示价格、描述等业务信息。

### 3.6 设置窗口 UI

- 视觉从像素奶茶主题调整为低饱和、可兼容不同包装颜色的中性主题。
- 使用 `18 pt` 圆角和统一 `2 pt` 外边框，并为透明窗口边缘预留对称渲染空间。
- 删除标题奶茶图案，标题改为居中的“设置”。
- 标题区高度为 `32 pt`，与提醒时间区域间距为 `12 pt`。
- 删除副标题、时间说明、可见“时分秒”标签、本机保存说明及装饰图形。
- 时间改为三个 `58 × 40 pt` 输入框加冒号，保留辅助功能标签。
- 提醒词输入框高度为 `48 pt`。
- 按钮文案从“保存设置”改为“保存”，默认不显示反馈，只在保存或校验后显示状态。

### 3.7 提醒气泡 UI

- 窗口缩小为 `268 × 128 pt`。
- 删除“奶茶提醒”标题和标题图标。
- 正文限制为两行，操作按钮统一为 `32 pt` 高。
- 外框和尖角使用与设置窗口一致的 `2 pt` 边框。
- 删除气泡阴影，修复透明窗口底部出现阴影带的问题。

## 5. 下一阶段任务

### 5.1 奶茶库与形象选择（P1）

- 确定奶茶数据的持久化格式和迁移策略。
- 增加奶茶列表、详情、创建、编辑和删除能力。
- 支持维护名称、价格、币种、描述、主图、贴纸和显示配置。
- 设置当前桌面茶宠，并验证应用重启后仍能恢复选择。
- 明确图像缺失、资源删除和无效 ID 的兜底行为。

### 5.2 提醒结果与记录（P1）

- 区分“来一杯”和“今天不喝”的实际业务行为。
- 增加饮用记录、价格统计和历史列表。
- 评估“稍后提醒”及临时跳过功能。

### 5.3 macOS 系统通知（P2）

- 请求并管理通知权限。
- 保存设置后注册或替换本地通知。
- 明确系统通知与桌面气泡同时存在时的展示策略。
- 处理应用退出、休眠和重新启动后的提醒恢复。

### 5.4 提醒规则增强（P2）

- 支持多个提醒时间。
- 支持工作日、星期、自定义重复周期和临时停用。
- 为设置结构增加版本和迁移能力。

### 5.5 桌面集成（P2）

- 增加菜单栏入口。
- 支持登录时启动。
- 增加更多悬停、点击或状态反馈动效，同时保持默认安静。
