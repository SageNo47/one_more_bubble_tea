# MilkTeaPet 当前功能与页面说明

> 文档基于当前代码整理，用于记录产品现状和支持后续迭代。

## 1. 应用概述

MilkTeaPet 是一款 macOS 桌面悬浮奶茶宠物应用。应用启动后不展示传统主窗口，也不常驻 Dock，而是在桌面上显示一个可拖动、始终置顶的像素奶茶形象，并提供每日定时提醒。

- 运行平台：macOS 13 及以上
- 技术实现：SwiftUI + AppKit，Swift Package 可执行程序
- 视觉风格：像素风、奶茶色系、硬边框与色块阴影
- 数据存储：本机 `UserDefaults`

## 2. 页面与界面说明

### 2.1 桌面奶茶宠物

应用启动后的默认界面，尺寸约为 112 × 140 pt【需要更改到合适大小，但还未定】，默认显示在主屏幕右上区域。

当前功能：

- 始终置顶，并可显示在所有桌面空间中。
- 可通过拖动宠物窗口调整位置。
- 奶茶形象会持续左右轻微摇摆。
- 杯身带有“叶师傅”像素贴纸。【这个后续删掉】
- 单击宠物：打开或关闭提醒设置面板。
- 右键宠物：显示菜单，包括“设置…”和“关闭”。【“设置...”需改成“设置”】
- 移动宠物时，已打开的设置面板和提醒气泡会同步重新定位。【后续改成：提示气泡随宠物移动，但设置面板始终放在桌面中间】

### 2.2 提醒设置面板

点击宠物或右键选择“设置…”后显示，尺寸约为 340 × 300 pt。面板优先出现在宠物下方；空间不足时会自动调整方向和位置，避免超出当前屏幕可见区域。【之后改成：设置面板始终放在桌面中间】

可配置内容：

- 提醒时间：填写以修改提示时间。
- 提醒词：支持输入 2～4 行自定义文案。
- 保存：将时间和提醒词保存到本机，并短暂显示“已保存 ✓”。【改成“已保存到本机”】
- 关闭：点击右上角“✕”、再次点击宠物，或再次选择“设置…”。【改成只通过点击右上角“✕”关闭】

默认配置：

- 提醒时间：15:00
- 提醒词：今天要不要来一杯奶茶呀？🧋

### 2.3 奶茶提醒气泡

到达设定时间后显示，尺寸约为 252 × 190 pt。气泡优先出现在宠物上方，空间不足时自动显示在下方，并同步切换气泡尖角方向。【注意用户拖动宠物位置后，也要相应变化提示气泡出现位置，让气泡每次出现都是在宠物上方】

界面内容：

- 标题：“🧋 奶茶提醒”
- 正文：用户在设置面板中保存的提醒词，最多显示 4 行
- “来一杯”按钮：关闭当前提醒气泡
- “今天不喝”按钮：关闭当前提醒气泡

目前两个按钮仅在文案和样式上不同，实际行为均为关闭气泡，尚未记录用户选择或产生后续动作。

## 3. 提醒机制

- 应用运行期间每 30 秒检查一次时间。【可以改成随时触发吗？难道做不到吗？】
- 当当前时间落在设定时间后的 60 秒内时触发提醒。
- 同一次应用运行中，同一自然日最多触发一次。
- 修改设置后无需重启，后续检查会读取最新配置。

## 4. 当前范围与限制

- 应用退出后不会后台提醒；当前未使用 macOS 系统通知中心。
- 电脑休眠或应用未运行时，提醒可能错过，醒来后不会补发超出 60 秒窗口的提醒。
- “来一杯”和“今天不喝”暂未关联打卡、统计或稍后提醒。
- 提醒时间目前仅支持每天一个固定时间，不支持多个提醒、工作日或重复规则。
- 配置仅保存在当前设备和用户账户中，没有云同步。
- 像素素材中预留了两个画面，但当前实际动效只有整体左右摇摆，尚未播放眨眼、吸管摆动等逐帧动画。
