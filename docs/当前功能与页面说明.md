# MilkTeaPet 当前功能与页面说明

> 本文档基于当前代码整理，用于记录已经实现的产品状态，并为后续奶茶库等功能提供开发依据。

## 1. 应用概述

MilkTeaPet 是一款 macOS 桌面悬浮奶茶宠物应用。应用启动后不展示传统主窗口，也不常驻 Dock，而是在桌面显示一个可拖动、始终置顶的奶茶插画，并按用户设置的本地时间显示提醒气泡。

- 运行平台：macOS 13 及以上
- 技术实现：标准 Xcode macOS App + SwiftUI/AppKit，Domain 与 Persistence 独立 Targets
- 当前视觉风格：可爱扁平插画、低饱和中性色 UI、圆角粗边框
- 本地存储：设置使用 `UserDefaults`，奶茶业务数据使用 Core Data

## 2. 页面与交互

### 2.1 桌面奶茶宠物

桌面宠物窗口尺寸为 `112 × 140 pt`，默认显示在主屏幕右上区域。

当前行为：

- 窗口始终置顶，可显示在所有桌面空间中。
- 可以拖动奶茶调整位置。
- 奶茶一般保持静止；鼠标进入图案区域时触发一次约 `0.55s` 的整体左右摇动。
- 已取消持续摆动、眨眼和吸管单独摆动。
- 已删除原像素杯身上的“叶师傅”贴纸以及 `StickerBadge` 组件。
- 已用透明 PNG 插画资源替换原像素网格绘制，采用高质量插值显示。
- 单击奶茶打开“喝了么”记录窗口；窗口已经打开时会刷新数据并置前，不会切换关闭。
- 右键菜单依次提供“记录”“设置”和“关闭”。
- 移动奶茶时，已显示的提醒气泡会持续跟随；设置窗口位置不受影响。

### 2.2 设置窗口

设置窗口初始尺寸为 `400 × 300 pt`，最小尺寸为 `360 × 280 pt`，支持拖拽调整大小。每次新打开时，窗口居中到奶茶当前所在屏幕的可见区域；打开后可拖动，重复打开会保留当前位置并置前。

视觉与布局：

- 使用低饱和米白背景、`18 pt` 圆角和统一的 `2 pt` 暖灰棕色边框。
- 顶部不再显示奶茶图案，标题简化为居中的“设置”。
- 标题区高度为 `32 pt`，标题与提醒时间区域间距为 `12 pt`。
- 右上角保留圆形关闭按钮。
- 表单内容保持 `24 pt` 左右边距，区域间距采用统一的 8 pt 基础网格。
- 已移除装饰圆形、像素硬阴影和多层卡片效果。

可配置内容：

- 提醒时间：三个 `58 × 40 pt` 输入框分别输入小时、分钟和秒，中间使用冒号分隔。
- 页面不显示“时、分、秒”提示字，但三个输入框保留“小时、分钟、秒钟”的辅助功能标签。
- 提醒词：单行输入框，高度为 `48 pt`。
- 保存：按钮文案为“保存”，尺寸为 `96 × 40 pt`。
- 时间必须在 `00:00:00–23:59:59` 范围内，提醒词去除首尾空白后不能为空。
- 默认不显示底部提示；保存成功后显示“已保存”，校验失败时显示对应错误。
- 关闭方式为右上角关闭按钮。

已删除内容：

- “给今天留一点甜”副标题。
- “每天按设置时间提醒”说明。
- “时、分、秒”三个可见标签。
- “测试气泡”按钮及其完整测试提醒调用链。
- “设置只会保存在这台 Mac 上”提示。
- 保存按钮中的勾选图标以及“保存设置”旧文案。

默认配置：

- 提醒时间：`15:00:00`
- 提醒词：`今天要不要来一杯奶茶呀？🧋`

### 2.3 提醒气泡

到达设定时间后显示，窗口总尺寸为 `268 × 128 pt`，其中气泡主体高 `120 pt`，尖角为 `14 × 8 pt`。

定位规则：

- 优先显示在奶茶上方；空间不足时显示在下方，并同步切换尖角方向。
- 显示前读取奶茶窗口的实时位置；显示期间监听窗口移动并持续跟随。
- 优先保证气泡完整位于当前屏幕可见区域，并保留 `12 pt` 屏幕边距。
- 设置窗口和提醒气泡的定位互相独立。

界面内容：

- 已移除“奶茶提醒”标题和标题图标。
- 正文直接显示已保存的提醒词，字号为 `14 pt`，最多两行。
- “来一杯”和“今天不喝”按钮高度均为 `32 pt`，间距为 `8 pt`。
- 气泡及尖角使用与设置窗口一致的 `2 pt` 边框。
- 已移除气泡投影，避免透明窗口底部出现灰色阴影带。

“来一杯”会先保存当天饮用记录；保存成功后关闭气泡，并在桌面宠物上方连续播放两次、总计约 `1.65s` 的棕色“+1”向上冒泡动效。保存失败时保留气泡并显示轻量错误提示，允许重试。“今天不喝”仍然只关闭气泡。

### 2.4 “喝了么”记录窗口

记录窗口初始尺寸为 `780 × 560 pt`，最小尺寸为 `700 × 480 pt`，支持拖拽调整大小；左侧月历会在较窄窗口中自适应宽度，右侧日期详情使用剩余空间。新打开时居中到宠物所在屏幕，打开后可独立移动；重复打开只刷新数据并置前。

- 顶部显示“喝了么”和关闭按钮。
- 左侧支持切换上月、下月及返回今天，并显示本周和当前浏览月份的杯数。
- 日历以周一为首日；周日日期颜色与其他日期一致。
- 有记录的日期显示奶茶小图和杯数，无记录日期不显示数量。
- 选中日期后，右侧展示日期、当天杯数和逐杯记录时间。
- 可以为今天或历史日期增加一杯；未来日期允许浏览但不能新增。
- 每杯记录可单独删除，删除后日期杯数和周/月统计立即更新。
- 记录来源保存在数据层，但当前界面不展示“来自提醒”或“手动添加”等来源文案。

## 3. 数据模型与存储

### 3.1 提醒设置

`ReminderSettings` 当前包含：

- `hour`
- `minute`
- `second`
- `message`
- `selectedMilkTeaID`

为兼容已有配置，时间仍以 `HH:mm:ss` 字符串保存在 `reminderTime`；旧的 `HH:mm` 配置会按 `HH:mm:00` 读取。提醒词和当前奶茶 ID 分别保存到独立的 `UserDefaults` 键。页面和状态对象通过 `SettingsRepository` 访问设置，不再直接依赖 `UserDefaults`。

### 3.2 奶茶模型

已新增 `MilkTea`、`MilkTeaDisplayConfiguration` 和 `MilkTeaStore`，为后续奶茶库和形象切换提供统一数据入口。

每个奶茶模型可保存：

- 稳定 ID 和名称
- 主图资源名
- 可选贴纸资源名
- 价格最小货币单位 `priceMinorUnits`
- 币种代码 `currencyCode`
- 描述 `description`
- 显示缩放和偏移配置

当前内置一个“黑糖珍珠奶茶”数据项，价格暂为 `0`、币种为 `CNY`、描述为空、贴纸为空。启动时由 `CoreDataMilkTeaRepository` 写入并读取，重复启动不会重复创建。当前 UI 不展示价格和描述；设置窗口也已按最新设计移除奶茶缩略图。桌面宠物仍由 `MilkTeaStore.selectedMilkTea` 驱动，当前选中 ID 作为设置项持久化。

### 3.3 图像资源

- 奶茶插画位于 `Sources/MilkTeaPet/Resources/milk-tea-pet.png`。
- `Package.swift` 已启用 Swift Package 资源处理。
- `MilkTeaArtwork` 通过 `Bundle.module` 加载并缓存 `NSImage`。
- `AnimatedMilkTea` 只负责桌面悬停摇动，普通静态展示使用 `MilkTeaArtwork`。

### 3.4 饮用记录

每杯饮用行为使用独立的 `DrinkRecord` 保存，包含 UUID、本地自然日、创建时间、可选奶茶 ID 和来源。记录通过 `CoreDataDrinkRecordRepository` 持久化；日历归属使用 `LocalDay`，避免时区变化导致跨日。周/月统计均由记录实时计算，不单独保存汇总值。

## 4. 提醒机制

- 应用启动时直接预约未来一次匹配设定时、分、秒的单次计时器，不进行固定周期轮询。
- 当天目标时间仍在未来时安排到当天；目标时间已经到达、经过或恰好相等时安排到下一天。
- 提醒触发后继续安排下一个自然日的同一时间。
- 保存设置后立即取消旧计时器并按新时间重新安排。
- 不限制同一自然日的提醒次数；保存新的未来时间后可以再次触发。
- 电脑休眠前取消计时器；唤醒、系统时间或时区变化后重新计算。
- 休眠期间错过的提醒不会补弹；恢复后超过 60 秒窗口的旧提醒会被忽略。

## 5. 当前范围与限制

- 应用退出后不会后台提醒，当前未接入 macOS 系统通知中心。
- 仅支持每天一个固定提醒时间，不支持多个提醒、工作日规则或临时停用。
- “今天不喝”不保存跳过记录；当前也不支持稍后提醒。
- 奶茶库目前只有数据模型和单个内置数据，尚无列表、增删改、导入和选择界面。
- 奶茶价格和描述已进入模型，但当前没有实际编辑和展示入口。
- 配置仅保存在当前设备和用户账户中，没有云同步。

## 6. 后续迭代方向

- 实现奶茶库的数据持久化、管理和选择界面。
- 让用户选择的奶茶成为桌面茶宠形象，并支持每款奶茶的独立贴纸和显示配置。
- 接入 macOS 系统通知，提高应用退出或休眠场景下的提醒可靠性。
- 增加稍后提醒、价格记录和更丰富的历史统计。
- 支持多个提醒时间和更丰富的重复规则。
- 增加菜单栏入口、登录时启动和更多互动动作。
